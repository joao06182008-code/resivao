## HTML

Define a estrutura e o conteúdo da página web, organizando elementos como textos, títulos, imagens, links e formulários.

## CSS

Controla o aspecto visual e o layout da interface, aplicando estilos de cores, fontes, espaçamentos, alinhamentos e adaptando a exibição para diferentes tamanhos de tela (responsividade).

## JAVASCRIPT executado no navegador

Adiciona interatividade e comportamento dinâmico à interface do usuário, permitindo manipular o conteúdo da página em tempo real, validar formulários e responder a ações do usuário sem necessidade de recarregar a página.

## Node.js, SQL, MYSQL

atuam no lado do servidor, sendo responsáveis pela lógica de negócios, processamento de dados e gerenciamento do banco de dados
